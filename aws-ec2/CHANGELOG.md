# Changelog

## 2.0.0
- **Breaking:** IPv6 is now enabled by default. The instance requests one IPv6 address, the security group allows `::/0` egress, and the default `ingress_rules` catchall allows both `0.0.0.0/0` and `::/0`. Set `ipv6_enabled = false` for IPv4-only VPCs/subnets.
- Add `ipv6_enabled` variable and `ec2_ipv6_addresses` output.

## 1.7.0
- Add `ingress_rules` variable: per-port sources (`cidr_blocks`, `ipv6_cidr_blocks`, `security_groups`, `prefix_list_ids`) with a `"*"` catchall for ports without an explicit rule. Defaults to `["0.0.0.0/0"]` for the catchall, preserving existing behaviour.
- Explicit port keys also open that port, even if it is not in `published_ports`; an empty map closes all ingress.

## 1.6.1
- Fix: changing `root_volume_size` now forces instance replacement. The AWS provider resizes root volumes in place, which left the AL2023 partition and filesystem at their original size; the new size is included in `user_data` so the existing `user_data_replace_on_change` behaviour recreates the instance and cloud-init grows the filesystem on first boot.

## 1.6.0
- Add optional `root_volume_size` variable to set the root EBS volume size in GiB. Defaults to `null`, which keeps the size from the AMI. Changing it on an existing instance forces replacement.

## 1.5.0
- Add optional `ami_id` variable to override the AMI. Defaults to `null`, which keeps using the built-in Amazon Linux 2023 AMI for `aws_region`. Also allows use in regions not in the built-in map.

## 1.4.0
- Add `cloudwatch_agent_enabled` (default: true) to optionally skip installing the CloudWatch agent.
- Add optional memory and disk usage metrics via `cloudwatch_metrics_enabled` (default: false), with `cloudwatch_metrics_interval` (default: 60) and `cloudwatch_metrics_namespace` (default: `CWAgent`).
- The agent config JSON is now generated by Terraform.

## 1.3.0
- Add support for attaching and mounting multiple persistent EBS volumes via `volumes` variable (map where key is mount point, value contains `id`, `device_name`, and optional `format`).
- Volumes must be pre-formatted with a filesystem (e.g., ext4) before attachment, unless `format = true` is set.
- Optional per-volume `format` parameter (default: false) enables automatic ext4 filesystem creation on unformatted volumes.
- Automatically mounts volumes and adds to /etc/fstab for persistence across reboots.

## 1.2.3
- Fix: Fixed indentation of generated shell script.

## 1.2.2
- Fix: Quote variable values in generated `.env` file for improved Bash compatibility.

## 1.2.1
- Add `aws_log_retention_days` variable (default: 90) to control CloudWatch log retention days for agent configuration.

## 1.2.0
- Add support for CloudWatch Agent installation and logs collection.
- Add `LOG_FILE` variable for install and run scripts with output redirection.
- `.env` file now includes EC2 config (`AWS_REGION`, `AWS_LOG_GROUP`, `EC2_HOSTNAME`).
- Improved environment variable and secret injection.

## 1.1.1
- Removed indenting from the .env file output.

## 1.1.0
- Added the `environment` variable for passing static environment variables to the instance.

## 1.0.0
- Initial release.
